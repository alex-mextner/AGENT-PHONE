# Render QA

Reviewed at final resolution before merge. The user explicitly accepted the new render direction; the old oversized/rotated baseline is no longer used by the public gallery.

## Mechanical checks

- [x] Scale comparison uses AGENT-PHONE 94 × 45 mm and two Watch Ultra-sized 49 × 44 mm references.
- [x] Long display axis is across the wrist.
- [x] Closed / 30° / 55° tilt states keep the hinge recessed.
- [x] Open cuff leaves the underside of the wrist free of a rigid battery/clasp block.
- [x] Curved battery plates are physically continuous with the cuff rather than floating bars.
- [x] Detachable module and exploded carrier are readable as separate mechanical layers.
- [x] Edge-to-edge glass dominates visually; structural rim stays subordinate.

## Lifestyle checks

- [x] Home/status, chat, marketplace, split, smart-home and blind-input UIs are rendered on-wrist.
- [x] Chat uses left chat list + right conversation pane.
- [x] Ring, glasses/private-audio, camera tile, TV handoff and desk-clearance contexts are visible.
- [x] External endurance battery is shown as an optional pack with a flat power ribbon; underarm/lower-back placement remains a body-worn packaging study, not a fixed production claim.
- [x] Car HUD is shown as a sparse navigation handoff target; ordinary notifications are intentionally absent while driving.
- [x] Dive concept uses the secure-clasp direction without changing the base open-cuff architecture.
- [x] New lifestyle renders use the licensed MakeHuman CC0 human asset pipeline, not the rejected cylinder/sphere proxy.

## Rejection criteria used

A render is rejected if it shows the old 90° orientation, an oversized phone-like slab, floating cuff batteries, obvious mesh clipping, a dominant exposed hinge, a thick picture-frame bezel, or a single-pane chat UI that wastes the wide display.

The technical and lifestyle contact sheets are convenience overviews; individual PNG files remain the source for full-resolution inspection.
