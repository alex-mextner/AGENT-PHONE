# Naming

## Working product name: AGENT

**AGENT** currently fits the concept best because the hardware is not primarily a watch or a phone. It is a physical endpoint for a personal agent and Agent OS.

The name should stay product-like rather than be expanded into an acronym.

Possible hierarchy:
- **AGENT** — device family;
- **AGENT One** — first general-purpose model, if a model name is needed;
- **AGENT Dive** — secure-clasp / water-focused version;
- **Agent Ring** — tactile and spatial input accessory;
- **Agent Glasses** — optional display / gaze / spatial accessory;
- **Agent Camera** — detachable camera tile.

## Passport

**Passport** is strong for the identity / residency layer rather than necessarily the physical hardware SKU.

Possible usage:
- "Your AGENT is your Passport."
- Passport credential / Passport wallet.
- Resident Passport as a cryptographic identity object that can live on AGENT but is not trapped in the hardware.

This distinction avoids implying that losing the device means losing identity.

## Screen

**Screen** remains useful as a plain-language category term:
- wrist screen;
- personal screen;
- primary Screen surface.

It is deliberately literal, but as a brand it is hard to search and difficult to distinguish from the generic noun.

## Telekinesis

**Telekinesis** is the working subsystem name for interaction without a visible keyboard:
- deliberate silent articulation;
- tiny finger movements;
- wrist gestures;
- ring input;
- gaze;
- spatial pointing;
- haptic/TTS correction.

It should be described as multimodal interaction, not as thought reading.

## Category language

Useful descriptive phrases:
- wrist computer;
- personal wrist computer;
- wearable personal computer;
- agent device;
- personal agent hardware;
- wrist screen.

Avoid forcing the product into an existing category before the interaction model is validated.

## Avoid for now

- **smartwatch** — anchors expectations to fitness/notifications and a small square face;
- **phone** — implies portrait apps, games and video consumption;
- **PDA** — historically related but culturally dated;
- **communicator** — useful in science fiction, but generic as a product name;
- **neural interface** — overclaims the sensing stack;
- **AI pin** — anchors the product to a failed/limited product category rather than its actual wrist interaction.
