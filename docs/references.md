# Visual references

See the **[visual moodboard](moodboard.md)** for the image-led comparison board with `KEEP / AVOID / WHY` notes.

This page is a design critique, not a mood-board to copy. External images remain hosted by their original sources; this repository does not redistribute those image files. Rights remain with their respective owners.

## Fallout — Pip-Boy

Official reference: https://fallout.bethesda.net/en-US/news/fallout-pip-boy-3000-replica

**Keep:** unmistakable "computer on the body" identity; dense information; physical confidence.
**Reject:** forearm-scale bulk, fixed viewing angle, deep chassis, requirement to rotate the whole arm toward the face.

Screen should feel like the elegant descendant of this category, not a mini Pip-Boy.

## Star Citizen — mobiGlas

![Star Citizen mobiGlas reference](https://cdn.mos.cms.futurecdn.net/v2/t%3A0%2Cl%3A118%2Ccw%3A700%2Cch%3A525%2Cq%3A80%2Cw%3A700/CCMTsUzeTD4kqbnyVBDSx4.jpg)

Source: https://www.pcgamer.com/star-citizen-video-show-off-smartwatch-style-ui-called-mobiglas/

**Keep:** landscape information architecture, wrist-local interaction, sense that the wrist is a portal rather than a watch face.
**Reject:** giant holographic plane, weak privacy, impossible outdoor projection assumptions.

Screen gets the landscape ergonomics with a real emissive panel and optional glasses.

## Mass Effect — Omni-tool / Andromeda UI

![Mass Effect wearable UI reference](https://mir-s3-cdn-cf.behance.net/project_modules/1400/818d2811430497.560f79c8260ad.jpg)

Behance reference: https://www.behance.net/gallery/51952829/Mass-Effect-Andromeda-User-Interface-Design

**Keep:** fast contextual tools, arm-local control, clear mode changes.
**Reject:** projected interface extending far beyond the wrist and constant luminous visual noise.

## Nubia Alpha

![Nubia Alpha](https://scr3.golem.de/screenshots/1902/Nubia_Alpha_Hands_on/thumb620/P2322030.jpg)

Source: https://www.golem.de/news/nubia-alpha-im-hands-on-flexibles-display-macht-die-smartwatch-gross-und-dick-1902-139657.html

**Keep:** real proof that an elongated flexible OLED can wrap with the wrist.
**Reject:** narrow portrait strip, thick side housings and "phone UI wrapped around a wrist."

Screen rotates the information architecture into landscape and keeps the curved volume for battery/strap transition, not for a tall app list.

## Real interaction references

### Meta Ray-Ban Display + Neural Band

https://about.fb.com/news/2025/09/meta-ray-ban-display-ai-glasses-emg-wristband/

This is the closest commercial validation of the Screen + glasses + wrist-EMG topology. We should not add a second wristband; Screen's own strap/base should host the EMG electrodes.

### Apple Vision Pro
https://support.apple.com/guide/apple-vision-pro/enter-text-and-use-dictation-tana14220eef/visionos

Useful interaction lesson: gaze selects context; a small pinch confirms. Screen should use this when glasses are present, while keeping primary operation possible without glasses.

## Design rules extracted from the references

1. Stay at the wrist, not high on the forearm.
2. Landscape first.
3. The display is one uninterrupted rectangle.
4. Hinge disappears when closed.
5. Battery volume follows the strap direction above/below the screen.
6. Never put a rigid block under the wrist.
7. UI is sparse enough to work on black OLED.
8. Glasses extend Screen; they do not become mandatory.
9. Projection is inspiration for spatial UX, not a V1 display technology.
10. Every render must prove how the object sits on an actual wrist.
