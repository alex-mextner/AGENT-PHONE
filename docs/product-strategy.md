# Product and distribution strategy

Status: hypothesis

## Base device

The base AGENT wrist computer is intended to be distributed free to a limited waitlist / early-resident cohort.

The purpose of free distribution is not to hide hardware cost. It is to maximize the installed base of a new interaction platform and to learn from real use before optimizing hardware margin.

## Paid extensions

Candidate commercial extensions:
- Agent Ring;
- multiple-ring kit;
- Agent Glasses;
- detachable Agent Camera;
- larger / external endurance battery;
- Dive cuff and clasp;
- specialist health sensors;
- premium materials;
- industrial / field versions;
- repair parts and replacement modules;
- enterprise integrations and support.

## Open platform

Core interfaces should be open enough for third parties to build:
- sensors;
- straps/cuffs;
- camera modules;
- power modules;
- Agent OS providers;
- data sources;
- spatial devices;
- local AI tools.

A free base device only works economically if accessories are genuinely optional and the platform does not deliberately cripple third-party alternatives.

## Waitlist

The waitlist should measure more than demand.

Useful questions:
- wrist size;
- dominant hand;
- willingness to wear a wide landscape device daily;
- desired battery life;
- interest in ring/glasses/camera;
- current phone usage categories;
- willingness to test screen-off text;
- professional/domain expertise;
- availability for structured prototype feedback.

Do not require sensitive identity or behavioral data just to join.

## Success metrics

Prototype programme:
- daily wear rate;
- median hours worn;
- interactions completed without taking out another device;
- messages composed with display off;
- display-on minutes per day;
- number of successful handoffs to TV/glasses;
- comfort complaints by wrist size;
- accessory attachment rate;
- battery endurance;
- failure/repair rate.

Business model:
- base hardware cost;
- accessory gross margin;
- support cost per active device;
- replacement-module rate;
- third-party ecosystem revenue if any;
- user retention independent of accessory purchases.

## Avoid lock-in

AGENT should not become "free hardware that only works if you buy proprietary services."

Design constraints:
- exportable data;
- replaceable service providers;
- open device APIs;
- no mandatory behavioral ads;
- no required cloud account for local core functions;
- accessories discoverable through standard/authenticated protocols where practical.
